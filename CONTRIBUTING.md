# Contributing

This repo receives agent-generated results. Keep it tidy:

- **One file per task** in `results/`, named `YYYY-MM-DD-<task>.md`.
- **Structured markdown** for anything longer than a paragraph (H1 + sections).
- **No secrets or binaries** — ever.
- **Small commits, clear messages**, pushed straight to `main` (it is an
  output channel, not a codebase — no review flow needed).

Questions about the playground itself live in `/home/agent/workspace/playground`.
